During the development of the IP Address Tracker project, I followed a step-by-step approach, starting with building the basic UI and then adding functionality using JavaScript. First, I implemented input validation to ensure users could only enter valid IP addresses. After that, I integrated the IPify Geolocation API to fetch location details such as city, region, timezone, and ISP. I then used LeafletJS to display the location on an interactive map and update the marker whenever a new IP address was searched.

Main challenge was protecting the API key during deployment. I resolved this by using Netlify environment variables and generating the secret.js file during the build process, which kept the key out of the GitHub repository. In Netlify, I added the API key as an environment variable called IP_API_KEY, which is only available during the build process. The scripts/make-secret.js file reads this environment variable and generates a secret.js file containing the line export const API_KEY = "actual_key_here";. This allows the frontend code to access the key without committing it to the repository. The netlify.toml file is configured to run this script before deployment using the command node scripts/make-secret.js and specifies the publish directory containing index.html. As a result, when the site is deployed, secret.js exists in the built site, enabling the frontend to use the API key. The key is never stored in GitHub, but it is present in the browser’s JavaScript when the site runs, which is acceptable for client-side applications.

If I have given more time,I would consider converting the project to React for better scalability and adding features like search history and dark mode. Overall, this project helped me strengthen my skills in JavaScript, API integration, error handling, and deployment.
